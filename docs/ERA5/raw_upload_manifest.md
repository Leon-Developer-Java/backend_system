# R11 ERA5 Raw Upload Manifest

Owner: Ma Junjie
Task: R11-ERA5-RAW-UPLOAD
Purpose: keep a raw-only ERA5 upload set for testing adapter parsing and update workflows, while keeping the curated default display assets that the frontend needs on first load.

## Upload Rule

For R11 raw-data upload, only upload original ERA5 NetCDF files (`*.nc`).

Do not upload locally generated parsing results:

- `data/ERA5/*.webp`
- `data/ERA5/*.meta.json`
- `data/ERA5/era5_index.db`
- `data/ERA5/*.png`

Exception: keep the already curated default ERA5 display assets that are intentionally tracked for frontend first-load display. New files generated by local manual parsing should stay local unless they are explicitly promoted to default demo assets.

## Default Frontend Display Assets

The currently retained default ERA5 display set is the parsed result of the global instant sample:

- `data/ERA5/data_stream-oper_stepType-instant_2.nc.meta.json`
- `data/ERA5/data_stream-oper_stepType-instant_2_*_step*.webp`

This set lets the frontend show ERA5 immediately on first load. Other local parsing results are ignored and should not be uploaded by default.
